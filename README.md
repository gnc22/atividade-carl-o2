# PRW2 - Avaliação 2: Catálogo de Filmes

Projeto React + Axios + React Router Dom desenvolvido para a disciplina de Programação para a WEB II (PRW2) do IFSP Câmpus São Carlos.

## 🚀 Tecnologias Utilizadas
- React (Vite)
- React Router Dom v6
- Axios
- MockAPI.io

## 🛠️ Como rodar o projeto localmente no VS Code

1. Extraia o arquivo zip do projeto.
2. Abra a pasta no VS Code.
3. Instale as dependências:
   npm install
4. Verifique a URL em `src/config.js`.
5. Inicie o servidor de desenvolvimento:
   npm run dev
